# Kurs przed recertyfikacją KPP

Interaktywny kurs: 4 tygodnie po 5 lekcji, filmy z Dysku Google, quizy z bazy 278 pytań, bank błędów i egzamin próbny.

Strona: https://wnasilow.github.io/kpp/

Postęp zapisuje się w pamięci przeglądarki (localStorage). Między urządzeniami przenosisz go przyciskami „Eksportuj / Importuj postęp” na stronie głównej kursu.
